# Sources and credits — 03.05

Primary documentation checked September 7, 2026:

- [Cursor Agent overview — checkpoints](https://cursor.com/docs/agent/overview): local Agent snapshots and the documented restore controls. Treat the visible installed behavior as the evidence for this recorded experiment.
- [Cursor Agent troubleshooting](https://cursor.com/help/troubleshooting/agent-issues): local checkpoints are separate from Git; use Git for permanent version history.
- [Git restore reference](https://git-scm.com/docs/git-restore): source selection, working-tree and staging-area destinations, and path scope. The basic flags demonstrated are supported by the installed Git 2.43.0.

The isolated course environment uses Cursor 3.19.13. Agent work is recorded from the native editor using the existing High Fast selection. Model behavior, layout, shortcuts, and restore dialogs can vary with the installed version or settings.

The interactive companion is original Superposition course material. Its Git state model does not execute commands in the student's repository. All twelve supported source/destination/path combinations were separately compared with actual Git operations in disposable local fixtures. Six combinations outside this model's scope are disabled.

No authentication screens or private configuration are included in the selected lesson footage or starter bundle.

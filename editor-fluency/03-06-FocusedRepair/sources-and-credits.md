# Sources and credits — 03.06

Primary documentation checked September 7, 2026:

- [Cursor Inline Edit](https://cursor.com/help/ai-features/inline-edit): selected-code editing and the Windows/Linux Ctrl+K shortcut.
- [Cursor reviewing and testing](https://cursor.com/learn/reviewing-testing): inspect generated changes and distinguish behavioral checks from structural checks.
- [Node.js 22.23.2 test runner](https://nodejs.org/download/release/v22.23.2/docs/api/test.html): the installed version's test runner and spec reporter.
- [ECMAScript ToBoolean](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-toboolean): numeric zero and null both convert to false in a conditional.

The recorded environment uses Cursor 3.19.13, Node.js 22.23.2, and npm 10.9.8. Shortcuts, layout, and generated proposals can vary with settings and versions. The lesson records the actual installed Inline Edit interface and its proposal.

Operations Hub's queue preview is an original prepared course fixture. It consumes a real local API response generated from synthetic snapshots. The display bug was deliberately included for this exercise. The preview is not a production deployment and does not use a database or external service.

The interactive companion is original Superposition material. Its four fixed candidate expressions are teaching examples, not Agent output. Twelve candidate/input outcomes were checked against independently specified expected results. These checks do not modify repository files.

Selected footage and the portable student bundle contain no authentication screens or secret configuration.
